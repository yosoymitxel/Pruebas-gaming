# Publicar en itch.io

1. `npm run itch` → `terrario-isopodos-itch.zip` (todo dentro: sin CDN ni fuentes externas; ~1,3 MB).
2. En itch.io: *Kind of project* **HTML**, subir el zip y marcar **This file will be played in the browser**.
3. Embed: 960 × 600, **Mobile friendly** (orientación automática), **Fullscreen button** activado.
4. Modelos 3D de bichos: Polyfork (uso comercial sin atribución). Fuente Caveat: SIL OFL.
