# Dirección visual

- **Referencia central:** qué objeto o idea organiza todo (para el terrario de isópodos: el terrario).
- **Escena:** diorama 3D con cámara inclinada que gira; el pase de tinta (`src/view/ink.js`) da contorno,
  punteado y aguada. Filtros: tinta, CRT, papel viejo.
- **Interfaz:** papel, borde de tinta, sombra dura; botones ≥ 48 px, foco visible, movimiento reducido respetado.
