# Skills propias y curadas

Esta carpeta contiene skills originales del repertorio o adaptaciones mantenidas por el proyecto.

Las skills externas instaladas mediante el instalador se copian a las rutas de agentes (.agents/skills y .claude/skills) para que queden versionadas en Git. No copies manualmente el mismo contenido aquí sin una razón clara: evita duplicados divergentes.

Para cada skill propia, incluye:
- SKILL.md con name y description.
- Disparadores claros y casos de uso.
- Procedimiento y criterios de validación.
- Procedencia/licencia si deriva de una fuente externa.

La skill local inicial está en .agents/skills/game-project-orchestrator/SKILL.md.
